# Motion graphics — showing what cannot be filmed

Graphics exist to make un-filmable information visible at the exact moment the narration names it. Decoration is banned; every graphic answers a line.

## The toolkit (in priority order for LedgerFilms)
1. **Figure builds** — a number counts up, a bar grows, a line climbs/drains, in sync with the spoken figure. One number per graphic; the spoken digit and the visual land together.
2. **Mechanism diagrams** — 3–5 boxes/nodes maximum, arrows lighting up in the order the narration names the steps (money flow, data flow, traffic flow). Reused and extended across the video, so the diagram becomes a familiar place.
3. **Document pushes** — a slow push-in on a stylised filing/letter (no fake readable text beyond the one short attributed quote, set as overlay type, with its source named on screen).
4. **Maps & timelines** — a location lights up when named; a date marker advances along a timeline spine at each dated event.
5. **Lower-third identification** — name + role + source the first time a person/company/statistic appears (“Steve Huffman, CEO — earnings call, 29 Oct 2026”), which is also the channel's attribution discipline made visible.
6. **Kinetic emphasis** — one short phrase (≤4 words) set large at the turn and the lesson only (“THE DOOR CLOSED”).

## The figure rule (OWNER CORRECTION 2026-11-07 — proof rated 6/10, “for data better infographics”)
Every load-bearing figure in the narration — a money amount, a percentage, a count, a date — gets a **planned GRAPHIC beat in the screenplay's VISUAL column** at the clip where it is spoken: a figure/bar/line build, a mechanism diagram, a map light-up, a timeline advance, or a document push. A big number spoken over abstract art does not count as showing the data. Where the video model cannot render digits cleanly (garbling), the build is shapes-only in the generated clip and the exact figure + source is set as a timed editor overlay in the channel style (amber on deep teal/charcoal) at the clause that names it. The screenplay lists each planned overlay (text, source, clip, timing) so the editor step is execution, not improvisation.

## Craft rules
- **One graphic idea per shot**, entered cleanly (fade/build ≤0.5s), held long enough to read (≥ the time to read it aloud), exited cleanly. No bouncing, spinning or zooming text — VideoExpress's Fast Cut Zoom stays OFF; graphics move by build and reveal, not by effects.
- **Style lock:** same type family, weight, colour (amber on deep teal/charcoal), position grid and easing for every graphic in every video — the channel's visual signature.
- **Sync rule:** the graphic is timed to the clause that names it, not the paragraph. If the narration says “a million fewer every week”, the counter drains as the words land.
- **Honesty rule:** charts show only sourced figures, labelled with source + date on the graphic itself; conditional/attributed claims are labelled as such in the graphic (“company estimate”, “CEO, earnings call”). A graphic never upgrades a claim's certainty.
- **Tool reality check:** VideoExpress offers text overlays and clip motion but no true dissolve or chart animation; anything beyond a timed overlay/build is finished as a rendered graphic clip or in an external editor step — plan it in the screenplay's VISUAL column (“GRAPHIC: …”) so it is budgeted, not improvised.
