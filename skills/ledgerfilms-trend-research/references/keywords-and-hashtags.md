# Keywords & hashtags — the pack that ships with every video

Build this **from the trend research, not from a generic list**: YouTube autocomplete
phrases, Google Trends related/rising queries, the wording in the Reddit threads and
comments that surfaced the topic, and the proven search phrasings in the niche
("how X makes money", "rise and fall of X", "why X failed", "X explained").
Fill it into `../../../templates/upload-metadata.md` at handoff (PLAYBOOK §10).

## Rules that apply everywhere

1. **One primary keyword per video** — the phrase the whole pack is built around
   (usually company/founder + the mechanism question). It goes in the title, the
   first two lines of the description, and as the first tag.
2. **Viewer language only.** A keyword qualifies only if a real viewer would type
   it. No keyword stuffing, no keyword repeated in different word orders to fill a
   quota, no terms the video doesn't actually answer (that kills retention and
   trust, and platforms demote it).
3. **Company + founder + mechanism** are the three keyword families: the name
   people search, the person they search, and the question they ask. Every pack
   covers all three that apply.
4. **Hashtags are topics, not sentences.** 1–3 words each, no spaces, CamelCase for
   multi-word tags so screen readers read them right (#BusinessStories, not
   #businessstories, when the platform preserves case).
5. **No advice/bait tags** — no #InvestingTips promising returns, no stock-ticker
   hype tags, no "will crash" phrasing (see the skill's hard rule 4).
6. Rotate the channel tags; don't paste the identical hashtag block on every video.
   Only the 2–3 true channel constants repeat: **#LedgerFilms #BusinessStories**
   (and #Shorts family rules below).

## Per platform

### YouTube — long-form
- **Title:** primary keyword inside the curiosity formula; ≤60 characters where possible.
- **Tags:** primary keyword first, then 8–15 phrases (company, founder, mechanism
  question, pillar phrase, 2–3 autocomplete variants) — total within YouTube's
  ~500-character tag budget; cut the weakest rather than truncating mid-list.
- **Description:** primary + 2 secondary keywords naturally in lines 1–2; chapter
  titles reuse search phrasing; **3 hashtags max** at the end of the description
  (the first 3 are the ones YouTube displays above the title) — pick the broadest
  true ones, e.g. #Business #Entrepreneurship #HowMoneyWorks — fitted to the video.
- **Also set:** playlist by pillar; end-screen target is the related video the
  outro set up.

### YouTube — Shorts
- **Title:** the hook itself (≤100 characters), primary keyword inside it.
- **Hashtags:** `#shorts` plus 2 topical ones in the description — 3 total. More
  dilutes, not helps.
- Pinned comment links the related long-form (that's the funnel — keywords get the
  view, the pinned link gets the session).

### TikTok
- **Caption:** hook line with the primary keyword in the first sentence, then
  **3–5 hashtags**: 1 broad (#BusinessTok / #FinanceTok fitted to the topic),
  1–2 topical (company/mechanism), the channel constant #LedgerFilms.
- Use the exact phrase viewers search on TikTok too — TikTok search is a real
  discovery route for explainers; don't keyword-stuff the caption to feed it.

### Instagram Reels
- **Caption:** hook first line, primary keyword in the first two lines.
- **Hashtags:** 5–10, mixed sizes — 2 broad (business/money), 3–5 mid-size topical,
  1–2 specific (company/founder name). Put them at the end of the caption or in
  the first comment — pick one habit and keep it consistent.

### Facebook (page / Reels cross-post)
- Plain-language title line with the primary keyword; **1–3 hashtags** (Facebook
  rewards the words, not the tags); the description carries the sources + the
  not-financial-advice line, same as YouTube.

### X
- No hashtag block. One hook sentence with the primary keyword as plain words,
  **at most 1–2 hashtags** if any, and the video/link. X is distribution + the
  argument starter (reuse the pinned-comment question), not an SEO surface.

## Deliverable format (per video)

Primary keyword · 3 title options with the keyword placed (pick marked) ·
YouTube tags list · YouTube description hashtags (3) · Shorts hashtags (3) ·
TikTok caption hashtags (3–5) · Instagram hashtags (5–10) · Facebook hashtags (1–3) ·
X line · the evidence each phrase came from (autocomplete / Trends / Reddit /
competitor demand) — one short note per family, so the pack can be audited later.
